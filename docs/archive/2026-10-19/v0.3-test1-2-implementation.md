## 1. 已确认并实施的契约

| 项目 | 本轮规则 |
| --- | --- |
| Node.env_file | 构造和赋值时固定绝对路径、检查文件存在；None沿用旧配置路径 |
| 独立账户 | Node显式参数优先，其次仅从该Node文件解析账户；不从系统环境或Graph补缺项；有效model、base_url和所选密钥须完整；自定义api_key_env只查该文件 |
| 数值参数 | Node显式temperature、max_output_tokens、timeout等优先，未设置时仍可继承Graph默认值；input_token_budget仍标记accepted_not_applied |
| 旧用法 | Node没有独立文件时，保留节点→Graph→系统环境→Graph文件→库默认的原有配置规则；两套账户字段的冲突规则在相应账户作用域内判断 |
| involve | 仅关键词参数nodes列表、relations普通二元组列表、必填entry；返回None；仅用于空Graph的一次成功装配 |
| 身份与关系 | 名称为node_<完整Node.id>；关系和入口传Node对象；无新增name或查找API，不按列表位置执行 |
| 重复和归属 | 拒绝重复节点身份、重复边、外图／已注册节点及已有连线、route或receive；重复装配拒绝，失败后仍可重新装配 |
| 校验与事务 | 注册、连线、入口和完整校验统一提交；失败恢复节点名称／归属／连接、Graph定义与编辑状态；装配不发API请求 |
| 方法名 | involve与run/result一样不能被实例属性或节点覆盖，旧同名节点需重命名；不扩大其他保留名规则 |
| 快照与导出 | 装配时校验配置，运行重新读取并冻结；相同文件每次编译只读一次；导出绝对文件路径和密钥引用，禁止密钥值 |
| 高级拓扑 | relations首轮只提供普通有向边；旧route/receive/edit保持现有能力和限制；多入边不自动变all汇合 |

密钥内部按节点ID与引用名隔离。即使两个文件都使用LLM_API_KEY，也不会覆盖彼此；共享同一文件的多个节点不需要复制文件。

## 3. test1-2 程序

[test1_2.py](../../../test/test1_2.py) 的两个Node分别配置env_file、输出token上限和提示词，Graph()通过involve接收节点、关系和入口。source输出CHAIN_A，经声明的关系传入target；target据此输出TEST1_2_OK，普通终点自动收集为Info。

source输出上限16 tokens，target为32 tokens；每节点尝试期限30秒、一次尝试。两节点本轮引用同一份已授权文件，不复制真实凭据；不同文件／不同账户的隔离由合成凭据与受控HTTP验证，不能写成双真实账户验收。

从D:/project/easy_agent根目录手动运行：

```powershell
& 'D:\anaconda3\envs\common\python.exe' -B -m test.test1_2
```

默认配置文件为D:/code/Python/agent/hello_agent/test.env，仅由运行进程读取模型字段，不修改文件或使用无关Tavily凭据。模块入口在受控测试中验证安全标准输出；本轮真实回归实际执行其run业务函数并保存框架事件证据，无额外独立真实调用。
