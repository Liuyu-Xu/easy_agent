## 1. 已落地行为

- test1_2及另外三个公开示例使用文件内ENV_FILE常量，无argparse、统一try/except、main函数或退出码包装。保留run(env_file=ENV_FILE)供Python代码和回归工具复用；导入不会运行图。
- 成功返回Info，示例打印业务文本；固定标记断言统一由tests负责，库不认识TEST1_2_OK等用例文本。
- 继续由Node配置账户文件和节点请求预算；test1-2上游16、下游32 tokens，30秒、一次尝试。既有Graph配置示例仍验证旧账户规则。
- common环境通过本地可编辑安装配置项目，不下载依赖。直接运行文件无需修改sys.path、工作目录或解析终端参数。
- 框架错误统一使用现有异常类别；有run_id时默认文本附带该ID，没有时不伪造。扩展代码的异常正文、用户提供的异常run_id及默认可见的原始cause/context不向调用者透传。
- 由库构造且描述未被改写的异常保留安全描述，例如HTTP 401；仅继承EasyAgentError的用户异常不自动可信。用户自定义异常子类的字符串方法不执行，转为对应边界的标准异常。
- Info的无效嵌套数据诊断使用结构占位符，不把业务字典键写进错误文本。日志IO和配置读取使用固定描述，默认格式化异常链抑制底层原始文本。
- 失败继续抛异常、停止运行并使result不可用；保留原取消、清理和并发隔离行为。未增加safe_run、第二套执行器或新的公开诊断字段。

内部错误工厂_safe_error负责构造和归一化，所有库生成的EasyAgentError类异常由它创建。来源标记是私有实现，用于避免误信任用户异常文本；它不承担隔离同进程任意代码的功能。不安装全局异常钩子，也不控制外部调试器的局部变量展示。

## 2. 接口职责与唯一实现

| 功能 | 对外入口 | 唯一实现与处理 |
| --- | --- | --- |
| 同步运行 | Graph.run(info) | run；旧graph(info)通过__call__ = run直接绑定同一个函数对象，无第二个函数 |
| 异步运行 | await Graph.arun(info) | arun；run仅负责同步调用适配，两者共用既有运行内核 |
| 读取结果 | Graph.result() | 只读取最近发起且成功的结果，不触发运行 |
| 首次整图装配 | Graph.involve(nodes, relations, entry) | 复用注册、连线、edit及compile，不增加第二套建图校验 |
| 追加／替换普通边 | Node.send_to／set_downstreams | 共用_set_downstreams；分别保留追加和整组替换语义 |
| 首次／替换路由 | Node.route／set_route | 共用_route；首次拒绝重复，替换允许已有声明；候选完整校验后一次提交 |
| 首次／替换汇合 | Node.receive／set_receive | 共用_receive；候选完整校验后一次提交 |
| Tool执行扩展 | Tool.forward | 基类不再声明重复invoke；仅在旧子类提供invoke时桥接 |
| 正整数／非负整数约束 | Node、Graph配置与运行覆盖 | 共用config._validate_int |
| 尝试次数与旧retry换算 | Node、Graph | 共用config._resolve_attempts；默认值和旧换算保持 |
| 账户和文件读取 | Node／Graph配置 | 继续复用_ConfigResolver及规范化路径缓存 |
| 框架错误呈现 | 原有异常类别 | 共用_safe_error及EasyAgentError.__str__ |
| 日志／审计查询 | Graph.logs、Graph.audit、Node.logs | 分类与对象范围不同，最终均使用EventStore.query |

“首次声明”“替换声明”“同步执行”“异步等待”“读取结果”具有不同的公开行为，不能仅因可调用相同内核就删掉其中一种能力。旧同步拼写已变成同一函数的绑定；当前文档与新示例统一推荐run。

明确删除的重复函数定义：

1. Graph.__call__的转发函数体，改为run的直接绑定。
2. Node._set_route，合并到_route。
3. Node._set_receive，合并到_receive。
4. Node._validate_positive_int及_validate_non_negative_int，改用共享整数校验。
5. Tool.invoke基类占位方法，forward为唯一工具执行扩展入口。
6. 四个公开示例中重复的main及CLI／错误包装。

另删除send_to的重复目标归一化、Graph／Node的重复尝试次数解析、Tool构造中的重复字段校验、路由／汇合替换时临时清空再回滚的实现。
