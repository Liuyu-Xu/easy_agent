## 2. T13-R01：执行并直接返回结果

### 2.1 公开调用

同步调用的唯一推荐写法：

```python
outputs = graph.run(inputs)
```

异步调用保留：

```python
outputs = await graph.arun(inputs)
```

直接返回结果的目标已实施；test1-3整改时输入仍为单个Info，随后test1-4按用户确认统一为list[Info]输入、list[Info]输出。同步与异步入口共用执行内核、输入校验和结果收集，不各自维护一套调度实现。

- 返回值只属于本次调用，调用者自行持有；同一图并发运行时，各调用分别取得自己的返回值。
- 本次调用失败则抛出异常，取消继续传播取消信号；不返回旧结果、错误字符串或伪造的成功结果。
- 不再提供公开 `Graph.result()`，也不新增 `get_result()`、`last_result` 等等价读取入口，不保留一个仅发出弃用提示后继续读取的 `result()` 包装。
- 不再规定“最近发起的一次运行”的业务结果可读性，也不要求 Graph 为此缓存成功输出。
- 取消公开 `result()` 不等于取消内部结果汇集、验证、来源记录及发布事件。
- 既有 `__call__` 属于先前的兼容入口，本项不授权删除它；保留期间仍只能直接复用 `run`，不得新增第二套执行路径。

### 2.2 覆盖的旧契约

本项作为下一轮实施依据，取代 [test1 整改文件](v0.3-test1-rectification.md) 中公开 `result()` 及最近发起运行结果读取的要求，并取代 [test1-2 简化指导](v0.3-test1-2-simplification-guide.md) 中对应的两步调用和结果读取验收。

迁移前：

```python
graph.run(inputs)
outputs = graph.result()
```

迁移后：

```python
outputs = graph.run(inputs)
```

示例函数可以直接 `return graph.run(inputs)`。用户示例不增加结果管理器、缓存包装或防御性检查。历史报告和证据保留原样，不能将当时的旧接口通过记录改写为新接口已通过。

## 3. 内部清理边界

| 当前内容 | 修改要求 |
| --- | --- |
| `Graph.result()` | 删除公开方法，并处理保留方法名、示例和测试中的对应引用 |
| `_ResultRecord`、`_latest_result`、记录开始／结束的辅助方法 | 检查引用后，删除仅服务于最近结果读取的状态和流程 |
| `_last_run_lock`、`result_record` 传递 | 按真实用途拆除，不能直接按名称整体删除；当前锁还参与运行 ID 赋值，需要保留日志／运行管理所需的同步 |
| 每次运行的上下文、`run_id`、执行状态和事件 | 继续保留，供调度、故障定位和来源追踪使用 |
| 异常边界的运行 ID | 当前异常归一化从结果记录取得本次 `run_id`；删除记录后须独立保留并传递该 ID，不能改读 `_last_run_id`，避免并发异常关联到另一调用 |
| 活跃运行计数、定义冻结、任务归属、取消和清理租约 | 继续保留；这些保护与公开结果缓存无关 |
| 内部结果收集和 `InfoPublished` 等事件 | 按最终确定的多出口协议迁移，保留每项输出的运行和来源信息 |
| `ResultError` | 检查非 `result()` 用途后再处理；当前还用于无有效出口或非法结果数量，不能因方法移除就整体删除异常类型 |

清理必须以引用关系和职责为依据，不通过删除并发、取消或日志保护来缩短代码。

## 4. 实施及验收要求

| 验收项 | 新要求 |
| --- | --- |
| 同步／异步成功 | 返回各自调用的业务结果，并复用同一内核 |
| 公开接口 | `Graph` 不再提供 `result()`，不出现等价结果读取替代接口 |
| 示例 | 直接使用或返回 `run`／`arun` 的返回值，不再调用 `graph.result()` |
| 同图并发、完成顺序颠倒 | 每次调用收到自己的结果；验证原有运行隔离和资源清理，不再验证“最近运行覆盖顺序” |
| 失败和取消 | 本次调用显式失败或取消，其他调用按各自状态完成；无旧结果回退；并发错误关联各自的运行 ID |
| 成功后再次失败 | 调用者已持有的旧结果仍属于旧调用；新调用不返回该结果 |
| 日志和来源 | 返回结果可关联正确的运行、节点及父 Info；移除缓存不破坏事件记录 |
| 测试工具 | `tests/api_support.py` 等从调用返回值验收；删除只证明 `graph.result()` 与返回值身份相同的旧断言，但保留来源、传递、异常、并发和清理检查 |
| 真实 API | 按 `AGENTS.md` 和 [API 轮次规则](v0.3-api-minimal.md)，使用 common 环境执行 `tests/run_api_round.py`，记录实际结果；失败不得算跳过 |

实施范围包括 `easy_agent/graph.py`、相关测试辅助、公开示例和当前使用说明。各文件共用现有验收能力，不再复制一份执行或结果检查实现。
