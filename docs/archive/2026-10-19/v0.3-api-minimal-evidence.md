## 1. 已交付行为

内置 Node.forward 已通过 Graph 调度发送真实 DeepSeek Chat Completions 请求；同步入口与异步入口共用 HTTPX 异步实现。库默认模型继续沿用既有定义，本轮测试显式使用用户文件中的 deepseek-flash。

每个业务 Task 通过私有 ContextVar 获取冻结配置、已解析密钥、尝试身份和剩余期限；上下文不写入共享 Node，退出时恢复，脱离 Graph 或跨 Task 复用被拒绝。每次尝试一个 HTTP 客户端，通过上下文关闭；传输重试与重定向均关闭。

role 和 prompt 固定映射为 system 文本，字符串及 JSON Info 映射为 user 文本。正常结束的正文形成字符串 Info，由现有运行器补全来源。默认显式禁用 thinking，实际 HTTP 参数包含模型、temperature、输出 Token 上限和非流式设置。

HTTP/网络/响应错误使用已存在的框架错误，不附原始响应正文或认证数据。模型调用日志记录 requested/reported model、finish_reason 和经过白名单处理的 usage；未知值保留为空。

## 4. 保留限制

详见 [最小 API 后续问题](v0.3-api-minimal-issues.md)。

当前范围是单次非流式文本输出，支持 None/str 输出 Schema；其他输出 Schema 和内部工具循环明确拒绝。自动重试、thinking 公共开关、严格模型身份、sequence、共享连接池扩展、可终止 Worker 与有限清理均未因本次集成而完成。

同步 graph(info) 可以执行异步 HTTP，但不能由此宣称所有自定义同步业务和 validator 都具有硬超时。原 S1-001—003 仍保留。
